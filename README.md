# Life OS — загрузки для Windows

Life OS — локальное desktop-приложение: страницы, базы, фотографии и настройки хранятся на вашем компьютере.

## Что скачать

- **Обычная установка (рекомендуется):** откройте [последний релиз](https://github.com/xsander-karp0vich/life-os-releases/releases) и скачайте файл `Life-OS-Setup-...-x64.exe`.
- **Portable без установки:** на той же странице скачайте `Life-OS-Portable-...-x64.exe`.
- **Проверка целостности:** SHA-256 опубликованы в `SHA256SUMS.txt` каждого релиза.

## Обновления

Версию `0.1.0-alpha.2` нужно установить вручную один раз. После этого Life OS проверяет обновления в фоне: **Настройки → Обновления → Перезапустить и обновить**. Локальные данные при обновлении не удаляются.

Исходный код хранится отдельно в приватном репозитории. Здесь публикуются только готовые Windows-сборки и метаданные обновлений.
